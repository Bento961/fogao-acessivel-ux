# 🧪 Projeto Prático – Redesign de Interface do Fogão Acessível

**Disciplina:** Desenvolvimento para Internet 1  
**Instituição:** Instituto Federal de São Paulo (IFSP - Campus Capivari)  
**Projeto:** Site de Apresentação de Interface Acessível e Usável para Fogão (Cooktop)

---

## 🧭 Sobre o Projeto

Este projeto consiste em um site estático desenvolvido exclusivamente com **HTML5 semântico** e **CSS inline**, abordando conceitos de UX/UI, usabilidade, acessibilidade e design centrado no ser humano.

O objetivo principal é apresentar o **InclusiveCook**, uma nova interface para um fogão de mesa (cooktop sem forno) projetada para garantir autonomia, inclusão e segurança para usuários com diferentes necessidades físicas, sensoriais e cognitivas (ex: pessoas com deficiência visual, motoras, daltônicos, cadeirantes, pessoas de baixa estatura, entre outros).

---

## 🎯 Seções do Site

1. **Apresentação do Projetista:** Reflexão sobre o papel do design empático e acessível no desenvolvimento de soluções do dia a dia.
2. **Nova Interface do Fogão:** Protótipo gráfico autoral criado no **Figma** detalhando a aplicação dos princípios da WCAG e W3C (alto contraste, relevos em Braille, mapa visual de posição, botões com ranhuras táteis e trava de segurança).
3. **Manual de Utilização Acessível:** Guia claro e objetivo passo a passo para operação e dicas de segurança acessíveis do equipamento.

---

## 🔧 Requisitos Técnicos Respeitados

- Estrutura em **HTML5 Semântico**.
- Formatação estilizada utilizando apenas **CSS Inline** (respeitando o escopo pedagógico da disciplina).
- Protótipo autoral desenvolvido no Figma (sem uso de Inteligência Artificial).
- Sem dependência de JavaScript ou frameworks externos.
